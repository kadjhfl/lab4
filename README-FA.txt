هەوراز - پروژه ساخت APK اندروید (نسخه دارای جست‌وجو)

این پروژه نسخه جدید آفلاین هەوراز را داخل یک برنامه اندرویدی قرار می‌دهد.
بخش جست‌وجوی سراسری و امکانات نسخه جدید در این بسته قرار دارد.
برنامه بدون اینترنت اجرا می‌شود و اطلاعات را روی همان گوشی نگه می‌دارد.
اطلاعات بین گوشی‌ها و لپ‌تاپ همگام نمی‌شود.

ساخت APK با GitHub Actions:
1) این ZIP را باز کنید.
2) وارد پوشه hawraz_android_build شوید و تمام محتویات آن، از جمله پوشه مخفی .github، را در ریشه مخزن آزمایشی GitHub بارگذاری کنید.
3) در GitHub وارد تب Actions شوید.
4) گردش کار Build HAWRAZ APK را انتخاب کنید و Run workflow را بزنید.
5) پس از پایان موفق، از صفحه اجرای workflow بخش Artifacts فایل HAWRAZ-Android-APK را دانلود کنید.
6) ZIP دانلودشده را باز کنید و app-debug.apk را روی گوشی اندرویدی نصب کنید.

اگر گزینه Actions دیده نمی‌شود، در تنظیمات مخزن GitHub اجازه اجرای Actions را فعال کنید.

نکته امنیتی: این رمز فقط قفل ساده داخل برنامه است و امنیت سروری یا رمزگذاری کامل داده‌ها نیست.
برای جلوگیری از از دست رفتن اطلاعات، از بخش پشتیبان‌گیری نسخه پشتیبان بگیرید.


اصلاح نسخه ۱.۲: نسخه Gradle به‌صورت صریح روی 8.9 تنظیم شده تا با Android Gradle Plugin 8.7.3 سازگار باشد.
محدودیت شناخته‌شده: چاپ فاکتورهایی که با پنجره جداگانه باز می‌شوند ممکن است در WebView فعلی اندروید کار نکند؛ این مورد هنوز در دستگاه واقعی آزمایش نشده است.
